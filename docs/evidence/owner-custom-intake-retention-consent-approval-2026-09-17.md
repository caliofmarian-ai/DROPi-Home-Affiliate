# Owner approval — Custom Furniture text-only privacy/consent checkpoint

Date: 2026-09-17

Project Owner approved the following implementation direction for the private text-only Custom Furniture intake pilot:

- retain pilot submissions for 30 days from submission unless a later real quotation/contract/dispute/accounting purpose requires a separately documented retention rule;
- continue implementation of the privacy and consent/acknowledgement layer;

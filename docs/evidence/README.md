# Evidence directory

Execution results in this directory are development evidence only. They are **not** editorial, legal, publication, brand or affiliate approvals. No `data/reviews.json` or site approval entry points to them as an approval.

`node-tests.tap` records executed Node tests. `browser-qa.json` describes the offline browser harness and its limitations. `build-and-gates.txt` records the build and expected launch HOLD. `execution.json` summarises the observed environment and missing external evidence. Screenshots show the local built UI, not a public deployment or physical Android acceptance.

Future approvals must be separately authored, explicit, dated and bound to the exact content/action by the relevant configuration and hashes. Never convert a test PASS into business approval.
